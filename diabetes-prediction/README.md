# Diabetes Prediction System (End-to-End ML)

A professional medical classification project that predicts the likelihood of diabetes based on diagnostic measurements. This project covers the full lifecycle: from **Exploratory Data Analysis (EDA)** and **Model Comparison** to a live **Web Deployment**.
[link](https://diabetes-prediction-lite.streamlit.app/)

---

## Project Overview

The goal is to predict whether a patient has diabetes based on health metrics like Glucose levels, BMI, Age, and Insulin. We achieved this by training a classification model on the **PIMA Indians Diabetes Dataset**.

### Key Highlights:

* **Model Comparison:** Evaluated both **Support Vector Machine (SVM)** and **Random Forest**.
* **Data Pipeline:** Includes feature scaling (Standardization) to ensure model stability.
* **Interactive UI:** Built a custom dashboard using Streamlit for real-time risk assessment.
* **Risk Analysis:** The app generates a visual "Risk Gauge" and personalized health recommendations.

---

## Technical Workflow

1. **Data Analysis:** Correlation heatmaps and distribution plots (Seaborn/Matplotlib).
2. **Preprocessing:** Handling outliers and applying `StandardScaler`.
3. **Model Selection:**
* **SVM (Linear Kernel):** Found the optimal hyperplane for clear class separation.
* **Random Forest:** Utilized an ensemble of 100 decision trees.


4. **Serialization:** Exported the trained model and scaler using `joblib` for production use.

## Dataset Information

The project uses the **[PIMA Indians Diabetes Dataset](https://www.kaggle.com/datasets/uciml/pima-indians-diabetes-database)** containing **768 records** with **8 features**:

| Feature | Description |
|---------|-------------|
| Pregnancies | Number of times pregnant |
| Glucose | Plasma glucose concentration (mg/dL) |
| BloodPressure | Diastolic blood pressure (mm Hg) |
| SkinThickness | Triceps skin fold thickness (mm) |
| Insulin | 2-Hour serum insulin (mu U/ml) |
| BMI | Body mass index (weight in kg/(height in m)^2) |
| DiabetesPedigreeFunction | Diabetes pedigree function (genetic influence) |
| Age | Age of the patient (years) |
| Outcome | Class variable (0 = non-diabetic, 1 = diabetic) |
